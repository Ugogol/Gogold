`package.json`. Il n'est donc pas encore un package du workspace pnpm.

(https://github.com/StakeEngine/web-sdk), en suivant la structure d'un jeu
officiel (`apps/lines` est l'implémentation de référence de la documentation).

Rien ne doit être développé ici avant cette intégration.
