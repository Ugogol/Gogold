# Contribuer à Gogold

## Branches

main
= version stable

feature/*
= nouvelles fonctionnalités

fix/*
= corrections

setup/*
= infrastructure et configuration

## Règles

Ne jamais développer directement une grosse fonctionnalité sur main.

Créer une branche.

Développer.

Tester.

Créer une Pull Request.

Appliquer la checklist correspondante de `docs/DEFINITION_OF_DONE.md`.
Le template de PR la rappelle.

Faire relire : pour une modification importante, l'auteur n'est pas le
validateur final.

Fusionner dans main.
